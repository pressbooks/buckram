Test 5: SCSS vs CSS Custom Properties

Old SCSS Approach:

// variables/_elements.scss $h1-color: $color-2 !default; $h1-text-transform: none !default; // components/elements/_headings.scss h1 { color: if-map-get($h1-color, $type); text-transform: $h1-text-transform; } // Theme override (functions.php) $styles->getSass()->setVariables([ 'h1-color' => '#b01109', ]);

New CSS Custom Properties:

/* buckram-variables.css */ :root { --h1-color: var(--custom-h1-color, #373d3f); --h1-text-transform: var(--custom-h1-text-transform, none); } /* components/headings.css */ h1 { color: var(--h1-color); text-transform: var(--h1-text-transform); } /* Theme override (CSS) */ :root { --custom-h1-color: #b01109; }

Benefits Demonstrated

  • ✅ No Runtime Compilation: Static CSS, no SCSSPHP needed
  • ✅ Browser DevTools: Inspect and modify variables in real-time
  • ✅ Simple Override: Theme customization via --custom-* prefix
  • ✅ Cascade Friendly: CSS natural cascade rules apply
  • ✅ Performance: No PHP processing at runtime
  • ✅ Maintainability: Standard CSS, easier debugging
