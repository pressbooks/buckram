Override Test

Purpose: Verify that --custom-* prefix variables can override defaults

Add this CSS to test overrides:

:root {
  /* Override heading color */
  --custom-h1-color: #b01109;
  --custom-h1-text-transform: uppercase;
  
  /* Override blockquote styling */
  --custom-blockquote-padding-left: 3em;
  --custom-blockquote-border-left-width: 5px;
  
  /* Override body typography */
  --custom-body-font-size: 18pt;
  --custom-body-line-height: 1.8;
  
  /* Override table borders */
  --custom-table-border-width: 2px;
  --custom-table-border-color: #3b82f6;
}

Expected Result: When custom overrides are added, all corresponding elements should reflect the new values.
